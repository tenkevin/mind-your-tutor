# QA criteria: A10 · Pre-send feedback safeguards

Done when: per D16, rubric grounding, a separate verifier, and a tone and reading-level check run before any feedback reaches a student; low confidence or disagreement routes to the teacher; a question whose audit drifts past threshold switches to teacher review automatically.
Sources: `docs/ARCHITECTURE.md` D15, D16, §9; A5 (grade bands), A9, M6. Mock models in tests.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| A10-F1 | must | Grounding | Feedback whose reason cites no rubric or key point | Blocked and routed to the teacher |
| A10-F2 | must | Verifier | The mock model marks a correct answer wrong | The separate verifier disagrees, so it goes to the teacher, not the student |
| A10-F3 | must | Tone and reading level | Feedback above the grade band's level, or harsh in tone | Rewritten or routed; the student never sees it as written |
| A10-F4 | must | Confidence routing | Low-confidence output | Routed to the teacher |
| A10-F5 | must | Drift switch (D16) | Push a question's M6 audit past threshold | AI feedback for that question switches to teacher review until a teacher clears it |
| A10-F6 | must | Order | Trace one feedback item | Safeguards run before `feedback.shown`; every block or route is logged with its reason |
| A10-F7 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| A10-S1 | must | Can't be bypassed | Call the feedback route without the safeguard step | Refused; there is no path from model output to a student that skips A10 |
