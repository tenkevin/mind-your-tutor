# QA criteria: F1 · Monorepo, CI, lint and test setup

Done when: pnpm workspaces build, lint and test in CI on every push.
Sources: `docs/ARCHITECTURE.md` §4 and §8.1, `AGENTS.md` Conventions.
Note: F1 merged before independent QA existed. This QA runs after the fact on `idea-map`. A FAIL is fixed by a follow-up task before F2 and F3 merge.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| F1-F1 | must | A fresh clone installs and builds | In a new container with Node 22: clone `idea-map`, `corepack enable`, `pnpm install --frozen-lockfile`, then `pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm test`, `pnpm build` | Every command exits 0 |
| F1-F2 | must | Every workspace from §4 exists | List `apps/*` and `packages/*` and read each `package.json` | Exactly teacher, student, api, worker, domain, tracker, contracts, connectors, ai, ui, db; each named `@ideamap/<name>` with `build`, `test` and `typecheck` scripts |
| F1-F3 | must | CI runs on pushes and PRs to `idea-map` and goes red on a failure | Open a throwaway PR into `idea-map` that adds `expect(1).toBe(2)` to one test; watch CI; then close the PR and delete the branch | The `build` job fails on that PR. On the current `idea-map` head, both `build` and `plan` are green |
| F1-F4 | must | The tracker determinism rule blocks clock, randomness and network | In `packages/tracker/src`, lint a scratch file containing each of: `Date.now()`, `new Date()`, `Math.random()`, `fetch('/x')`, `globalThis.fetch('/x')`, `performance.now()`, `crypto.randomUUID()`, `crypto.getRandomValues(new Uint8Array(4))`, `setTimeout(() => {}, 0)`, `import('node:http')` | Every one is an ESLint error; `new Date('2026-01-01T00:00:00Z')` is allowed |
| F1-F5 | must | The rule applies only to the tracker | Put `Date.now()` in `packages/domain/src/x.ts` and lint | No determinism error outside `packages/tracker` |
| F1-F6 | must | The plan tooling still works | `node scripts/plan.mjs check` and `node scripts/plan.mjs ready` | `plan: ok`; ready lists F2 and F3 |
| F1-F7 | should | The web apps start | `pnpm --filter @ideamap/teacher dev` and the same for student; open the printed URL | The page loads with no console errors |
| F1-F8 | should | The API starts and answers | `pnpm --filter @ideamap/api build` then run it; `curl localhost:3000/health` | `{"ok":true}` |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| F1-S1 | must | No known high or critical vulnerabilities | `pnpm audit --prod` and `pnpm audit` | No high or critical advisories |
| F1-S2 | must | No secrets in the repo | Run `gitleaks detect` (or `trufflehog git file://.`) over the full history of `idea-map` | No findings. `.env` and `.env.*` are in `.gitignore` |
| F1-S3 | must | CI runs with least privilege | Read `.github/workflows/*.yml` | `permissions:` is declared and is `contents: read` unless a job needs more; no `pull_request_target`; no secrets used |
| F1-S4 | must | Installs are reproducible | Check `pnpm-lock.yaml` is committed and CI uses `--frozen-lockfile` | Both true |
| F1-S5 | should | Third-party install scripts don't run unchecked | Check pnpm's install-script policy (`onlyBuiltDependencies`, or pnpm 10's default blocking) | Lifecycle scripts run only for an explicit allow list |
| F1-S6 | should | Actions are pinned | Read the workflow files | Third-party actions are pinned to a full commit SHA, or at least a major version from a verified publisher |
| F1-S7 | must | The API scaffold exposes nothing else | Build and run the API; request `/`, `/health` and a random path | Only `/health` answers 200; unknown paths return 404 with no stack trace |

## Performance

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| F1-P1 | must | CI is fast enough to keep a swarm moving | Read the duration of the last 3 CI runs on `idea-map` | `build` job median under 5 minutes |
| F1-P2 | should | Local test loop is quick | Time `pnpm test` from the root with a warm install | Under 60 seconds |
| F1-P3 | should | Starting web bundles are small | `pnpm build`, then measure gzip size of the JS in `apps/teacher/dist` and `apps/student/dist` | Under 80 KB gzip each. Record the numbers as the baseline |

## Usability (developers)

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| F1-U1 | must | The README's Development steps work exactly as written | Follow `README.md` → Development word for word in a fresh container | No undocumented step needed |
| F1-U2 | must | Determinism lint errors explain the fix | Trigger each F1-F4 case and read the message | Each message says what is banned and where time or randomness should come from (event data), and points to ARCHITECTURE.md §8 |
| F1-U3 | should | Adding a package follows an obvious pattern | Compare two package folders | Same file set and scripts; a new package can be made by copying one |
