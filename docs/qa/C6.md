# QA criteria: C6 · Exports: template, data-check and alignment reports

Done when: the template workbook, the data-check report and the alignment report download as files.
Sources: `docs/ARCHITECTURE.md` §7 (`ExportTarget`, the export list), D4 (import and export only), D8 (Curriculum Pack), D9, `docs/spec/curriculum-pack.fields.json`, `project/curriculum-pack.js` (`templateCSV`), `project/Curriculum Pack.dc.html`, the C2 issue type, and `fixtures/water-cycle`.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C6-F1 | must | Blank template workbook | Export the template, then import it with C1 | Eight sheets with exactly the spec's columns in spec order (including `Ideas.explanation`). Course has key/value rows. Imports with no errors except "no ideas" |
| C6-F2 | must | Template with sample rows | Export the sample template | The same sample rows as the prototype's `templateCSV(tab, true)` for every tab |
| C6-F3 | must | Template helps the teacher | Open the workbook | A header note or a "Read me" sheet with each column's type, whether it's required, and what happens when it's missing, taken from the spec |
| C6-F4 | must | Round trip | Export the water-cycle pack as a workbook, re-import it with C1 | Deep-equal to the original parsed pack |
| C6-F5 | must | Data-check report | Export the C2 report for the sample | A file listing the 3 issues (1 error, 1 warning, 1 info), each with level, message, ideas affected, and the tab and column to fix |
| C6-F6 | must | Alignment report | Export the standards alignment report for the sample | Per standards code: the ideas and units that cover it, matching the fixture (for example `MS-ESS2-4` lists every idea with that code). Ideas without codes are listed separately (`rain`). The framework name from Course labels the report |
| C6-F7 | must | Formats | Export each report as CSV and XLSX | Both open cleanly in Excel and Google Sheets, in UTF-8 (a BOM for CSV, so Excel shows accents correctly) |
| C6-F8 | must | Interface | Inspect the code | Each export implements `ExportTarget` from §7 |
| C6-F9 | should | Atlas drafts as rows | Export a set of drafted assessment rows | A CSV with exactly the Assessment tab's columns, ready to paste in |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C6-S1 | must | Spreadsheet formula injection is neutralised | Ideas titled `=HYPERLINK("http://x","click")`, `+cmd|' /C calc'!A0`, `-2+3`, `@SUM(1)`; export every report and the workbook, then open them | No cell is treated as a formula: values starting with `=`, `+`, `-`, `@`, tab or carriage return are escaped (prefixed with `'`) or stored as text. The round trip (C6-F4) still returns the original text |
| C6-S2 | must | Exports are scoped | Request another org's or class's report | 403 (when exposed through the API) |
| C6-S3 | must | No student data in curriculum exports | Inspect every export | Only curriculum data. No student names, progress or AI transcripts |

## Performance

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C6-P1 | must | Sample exports are quick | Time each export on the sample | Under 300 ms each |
| C6-P2 | must | Large packs | Export a 2,000-idea pack as XLSX | Under 5 seconds and under 256 MB peak memory |

## Usability (teachers)

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C6-U1 | must | Sensible file names | Look at the downloaded file names | Include the topic and date, for example `water-cycle-alignment-2026-10-22.xlsx`; no spaces or unsafe characters |
| C6-U2 | must | Reports are readable | Open each report | Plain column headers, idea titles rather than only ids, the most serious issues first, and frozen header rows in XLSX |
| C6-U3 | should | Matches the design's language | Compare the wording with Teacher Settings and the Curriculum Pack screen | The same tab names and terms |
