# QA criteria: S5 · UDL 3.0 baseline for the student app

Done when: shared student-app components give multiple means of representation, action and expression, and engagement; a UDL 3.0 checklist is added to the QA README for every student-facing task.
Sources: `docs/ARCHITECTURE.md` D17 (CAST UDL Guidelines 3.0 alongside WCAG 2.1 AA with D10's exceptions), D15 (spoken challenges), D19 (nothing extra recorded), §10; `project/Idea Map Explorer v2.dc.html`, `project/Milo.dc.html`, `project/Chat Panel.dc.html`; F2 `packages/ui`.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| S5-F1 | must | Representation: read-aloud | Use the shared component on an idea explanation, a quiz question and a feedback message | Each can be read aloud (browser speech synthesis, no network call and no third-party audio service), with pause and stop and highlighted text |
| S5-F2 | must | Representation: text and visual | An idea with media and one without | Text is always available; media has a caption or alt text slot; nothing is shown only as an image or only as colour |
| S5-F3 | must | Action and expression: spoken input | Answer a free-text prompt and a challenge by voice | Speech-to-text fills the text box for the student to check before sending; typed input always works; no audio is uploaded or stored |
| S5-F4 | must | Engagement: choice and pacing | Use the shared mission and step components | The student can choose among available missions, and multi-step tasks can be paused and resumed |
| S5-F5 | must | Adjustable presentation | Change text size to 200%, and turn reduced motion on | Layout holds; animations respect prefers-reduced-motion |
| S5-F6 | must | Checklist added | Read docs/qa/README.md | A UDL 3.0 section (engagement, representation, action and expression) that every student-facing task's criteria must include |
| S5-F7 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |
