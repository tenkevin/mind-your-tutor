# QA criteria: M1 · Tracker event catalogue and schemas

Done when: every §8.2 event type (D19) has a zod schema with its educational level; unknown types and forbidden fields are rejected.
Sources: `docs/ARCHITECTURE.md` D6, D18, D19, D20, D24, §8.1–§8.2 (spec v1); `packages/tracker` determinism rules (AGENTS.md); F4 `interaction_event` columns.

Boundary: M1 is schemas and types only. Ingest is M2; rules are M3.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| M1-F1 | must | Exact catalogue | Compare the exported event-type list with the §8.2 table | Same 17 types, no more and no fewer: idea.opened, idea.active_time, quiz.started, quiz.answered, quiz.finished, hint.requested, review.link_rebuilt, teachback.done, teachback.judged, feedback.shown, feedback.challenged, feedback.ruled, teacher.feedback.approved, teacher.feedback.edited, mission.completed, map.shown, ai.output_shown |
| M1-F2 | must | Level per type | Read each schema | The level matches §8.2 (participating, teaching or other) and is fixed by type, not supplied by the client |
| M1-F3 | must | Payload fields | Parse a valid sample of each type, then each with one field missing or the wrong type | Valid samples parse; every malformed one is rejected with a located error |
| M1-F4 | must | Rounding (D19) | Parse idea.active_time with 47 s and quiz.answered with secondsToAnswer 7 | Either rejected unless on the 30 s or 5 s grid, or normalised to 60 and 5 (documented which); the stored value is always on the grid |
| M1-F5 | must | Envelope | Parse the envelope (id ULID, studentId uuid, classId, versionId, seq, at, type) | Matches the F4 `interaction_event` columns; seq is server-set (client value ignored or rejected) |
| M1-F6 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| M1-S1 | must | Forbidden data can't enter (D19) | Add ip, userAgent, device, location, x/y coordinates, keystrokes, or a free-text field to any payload | Rejected (strict schemas: unknown keys fail) |
| M1-S2 | must | No free text in events | Inspect every payload schema | Typed text appears only as a `textRef` id, never inline |
| M1-S3 | must | Unknown types | Parse `link.hovered`, `zoom.changed`, `session.idle` | Rejected: these were removed by D19 |
| M1-S4 | must | Determinism (D6) | Run the tracker runtime guard and determinism tests | Pass; schemas add no clock, randomness or I/O to `packages/tracker` |
