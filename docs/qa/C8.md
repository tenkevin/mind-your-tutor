# QA criteria: C8 · Data-check and quiz quality fixes (from C2 and C3 QA)

Done when: the should-level findings in `docs/qa/reports/C2.md` (items 1–4) and `docs/qa/reports/C3.md` (items 1–4) are fixed, with a regression test for each.
Sources: those two reports, `docs/qa/C2.md`, `docs/qa/C3.md`, `docs/spec/curriculum-pack.fields.json`, `docs/ARCHITECTURE.md` §7. These are now **must**: teachers read the checks, and students read the quiz text.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C8-F1 | must | Assessment coverage counts ideas, not rows (C2 #1) | Unit 1 has ideas A and B with two Assessment rows, both for A; a row whose unit differs from its idea's unit; a row for unit 9, which isn't in Units | B is reported as having no question; the mismatched unit is a warning; the unknown unit is a warning (row skipped) |
| C8-F2 | must | Loop messages name every idea and give correct advice (C2 #2) | a→{b,c} with b→a and c→a; a→{a,b} with b→a | Every idea in the loop is named in the message, and the advice is right for the shape (no "remove one of these" when one removal isn't enough) |
| C8-F3 | must | Knock-on warnings are grouped (C2 #3) | 2 unknown prerequisites and 2 loops in a 2,000-idea pack; a 10,000-idea chain with a broken root | One knock-on issue per root cause, listing the affected ideas in `items`. The summary count reflects root causes (single digits here), not thousands |
| C8-F4 | must | Missing objective follows the spec (C2 #4) | An idea with `objective: null` | Handled as the spec's `missing` behaviour for that column says (flagged, or "Tutor writes one from links"), with a matching issue and a test |
| C8-F5 | must | Distractors never make a true sentence (C3 #1) | A pack where two ideas share a title; generate every "Which idea completes the link?" question | No distractor completes a sentence into a true statement from the pack |
| C8-F6 | must | Generated grammar handles plurals (C3 #3) | Titles "Glaciers", "Oceans", "Rain & snow"; category explanations; swapping a singular subject into a plural relation | "Glaciers are a thing", or a phrasing that avoids agreement ("Category: Thing"). No "Glaciers is". A test covers singular and plural titles |
| C8-F7 | must | Seeds are stored as used (C3 #4) | `derive` with `seed: 2**32 + 1` | The stored seed equals the seed actually used, or seeds outside 32 bits are rejected |
| C8-F8 | should | Real-world-true "False" statements are reduced (C3 #2) | Review false statements on the sample | Avoids swaps a teacher would mark true. If a rule can't do it, the PR documents why, and teachers can still flag a question later |
| C8-F9 | should | Small items (C2 #5–6) | An empty Categories tab; a link with both ends unknown | A warning for the empty tab; `fix` lists both columns |
| C8-F10 | must | Everything still passes | lint, format:check, typecheck, test, build, plan check | All exit 0; CI green; the C2-F2 sample result (1 error, 1 warning, 1 info) is unchanged |
