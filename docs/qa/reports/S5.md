## Found during testing

1. **Focused unnamed status (low, should; can't confirm without a real screen reader).** After "Send to my teacher", focus moves to `<p role=status tabIndex=-1>`. Chromium gives that node `name=""`, because status takes no name from its content. The text is a child, so most screen readers read it through the live region and when browsing. But some screen readers may say only "status" on focus, or read the message twice: once from the live region and once from focus. It may help to add `aria-labelledby` pointing at itself, or to focus a non-live wrapper. Steps: Challenge this → type → Send to my teacher, then inspect the focused AX node.
2. **Browser-level traffic, for the §10 inventory (info).** While Chromium ran, the agent proxy logged refused connections to `www.google.com:443`, including on runs where Talk was never pressed. That is Chromium's own background traffic, not the page's: the page made 0 requests to other origins. On first Talk, `install()` asks the browser to download the speech pack, as run 1 item 3 said. The explainer now warns that "your device may need a moment to get ready", so item 3 is handled in the UI.
3. **Talk stays visible while the explainer is open (low).** In run 1, Talk was hidden while the explainer was open. Now it shows, unpressed, after Not now, and pressing it closes the explainer. It works and keeps focus, but a K-2 student may not expect "Talk" to close the box. A coordinator could fold this into later usability review. It doesn't block.
4. **The 20 s getting-ready timeout is long (low).** The status says "Getting ready to listen…" the whole time, and Stop works, so the student is never stuck. Each new Talk press calls `install()` again (2 calls over two turns). That's harmless, because results from an old turn are ignored.
5. **Stored-format change (info).** StepFlow now stores `<step>` or `<step>p`. A value saved by the old build (`"1"`) loads as step 2, not paused, so the place is kept. No student data has shipped yet, so this has no effect in practice.
