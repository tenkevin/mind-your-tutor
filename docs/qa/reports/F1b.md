1. **A `*.test.*` file is exempt even when production code imports it, and it ships in `dist`.** Steps: write `export const clock = (): number => Date.now();` to `packages/tracker/src/clock.test.ts`, and add `export { clock } from './clock.test.js';` to `src/index.ts`. Results: `npx eslint packages/tracker/src/` exit 0, `pnpm --filter @ideamap/tracker build` exit 0, `dist/clock.test.js` is emitted, and `import('…/tracker/dist/index.js').then(m => m.clock())` printed `1792710102742`. `tsconfig.build.json` excludes `src/**/*.test.ts` only as roots, so an imported test file is still compiled. Suggested fix: a `no-restricted-imports` pattern banning `*.test*` imports in tracker code that isn't a test, or a lint rule or test that fails when `dist/` contains `*.test.*`. Suggested weight: **must** (for a follow-up task). It is a one-line way round the §8.1 rule.
2. **Reaching `Date` or `Function` through a prototype `.constructor` isn't caught.** `new Date(0).constructor.now()`, `new Date.prototype.constructor()`, `Object.getPrototypeOf(new Date(0)).constructor.now()`, `(function () {}).constructor('return Date.now()')()`, `(() => {}).constructor('return Math.random()')()` and `[].constructor.constructor('return Date.now()')()` all return the current time or a random value at runtime (for example `ctor 1792710055632`). Suggested fix: `no-restricted-properties` with `property: 'constructor'` in tracker code. Suggested weight: **should**.
3. **Spread and computed property names get past the `new Date()` and property rules.** `new Date(...[])` gives the current time (`2026-10-22T23:00:55.630Z`), because the selector checks `arguments.length=0` and a spread counts as one argument. `const k = 'now'; Date[k]()`, `Date['n' + 'ow']()` and `Math['ran' + 'dom']()` aren't flagged either, because `no-restricted-properties` only matches static names. Suggested fix: also match `NewExpression[callee.name='Date'] > SpreadElement`, and ban computed member access on `Date` and `Math` (`MemberExpression[computed=true][object.name=/^(Date|Math)$/]` with a non-literal property). Suggested weight: **should**.
