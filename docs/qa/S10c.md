# QA criteria: S10c · Close two D47 leaks in the student map API

Done when: the two should-level leaks found by S10b's QA (PR #48) are closed. A unit whose ideas are all hidden from the student no longer reveals its name. A far idea requested by its real id gets the same 404 response as an id that doesn't exist, so a student can't probe which ideas exist. An open idea's page doesn't name a far idea it links to (added 2026-10-30, found by the design session).
Sources: `docs/ARCHITECTURE.md` D47; S10b QA report (`https://github.com/tenkevin/mind-your-tutor/pull/48#issuecomment-6513525526`, the two security should findings); `apps/api/src/routes/student-map.ts`. Must-only fix task.
