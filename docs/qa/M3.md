# QA criteria: M3 · Deterministic tracker rules

Done when: packages/tracker implements §8.3 rulesVersion 1 (mastery, unlock, unit complete, XP and combo, streak, cards, "may need help" with reasons) as pure deterministic rules with property tests, and computes nothing D20 forbids.
Sources: `docs/ARCHITECTURE.md` D6, D20, D21, D24, §7 (unlocks are never taken away), §8.1, §8.3; `project/Idea Map Explorer v2.dc.html` (combo multiplier, pass bonus, unit bonus, streak); M1 catalogue; `fixtures/water-cycle/`.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| M3-F1 | must | Mastery and pass mark | Replay quiz attempts scoring 60, 70 and 80 against the default pass mark of 70 | Mastery % is the best score; the idea is mastered only by a score **above** 70 (80 passes, 70 does not) |
| M3-F2 | must | Unlock | Master every prerequisite of an idea, then publish a version adding a new prerequisite | Unlocked after the last prerequisite; stays unlocked after the publish |
| M3-F3 | must | Unit complete | Master every idea in a unit, with teach-back verdicts retry and then pass | Complete only after the pass |
| M3-F4 | must | XP maths | Replay 7 correct answers in a row, a wrong one, then a perfect passing quiz, a link rebuilt and a unit completion | XP is 10, 20, 20, 30, 30, 40, 40 for the run (190), then the combo resets; +50 pass, +50 perfect, +5 link, +200 unit, matching the prototype |
| M3-F5 | must | Streak | Passes on consecutive class-time-zone days, then a skipped day, including across a DST change | +1 per day with a pass; reset after a day without one; day boundaries in the class time zone |
| M3-F6 | must | May need help | Three wrong answers after a hint; an unlocked prerequisite of the next mission with no pass for 5 school days | A signal with a readable reason in each case; cleared by a later pass; never raised from durations alone |
| M3-F7 | must | Opt-out (D24) | The same events for an opted-out student | Identical outputs; the state marks the student excluded from audits and research |
| M3-F8 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |

## Security and integrity

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| M3-S1 | must | Determinism (D6) | Property test: random valid event sequences replayed twice, and with snapshots taken at random points | Byte-identical state every time; the runtime guard and F1c/F1d checks pass |
| M3-S2 | must | Nothing D20 forbids | Search the rules and their outputs | No risk, dropout or grade prediction; no engagement, behaviour or personality score; no clustering or ranking; durations are passed through, never scored |
| M3-S3 | must | Traceability | Ask for the events behind any output | The rules return the contributing event ids |
