# QA criteria: T8 · Publish screen: diff review and class picker

Done when: the teacher reviews the diff and checks, picks classes and publishes.
Sources: `docs/ARCHITECTURE.md` §7 (errors block publishing; diff contents; "Students receiving this update", D14; rollback by re-pinning), §11 (Draft and publish row), D2, D3; C5 API; T2 data checks; `docs/qa/C5.md` fixtures A, B and E.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| T8-F1 | must | Diff review | Open Publish for draft B against published A | Shows the C5 diff in teacher language: added, removed, renamed (old → new), prerequisite, unit-membership and question changes, by display name |
| T8-F2 | must | Checks shown first | Draft E (1 error) | The blocking error is shown with its fix; Publish is disabled with the reason |
| T8-F3 | must | Class picker | Two classes on the curriculum | Lists the classes the teacher may publish to, showing each one's current pinned version; none is pre-selected |
| T8-F4 | must | Students receiving this update (D14) | Select classes as in C5-F6 | Shows 4, then 2, then 0, labelled "Students receiving this update" |
| T8-F5 | must | Publish | Confirm publishing to class 1 | Calls C5 publish; a success state names the classes and the version; class 2 is untouched |
| T8-F6 | must | Rollback | From the class's version history, re-pin an earlier published version | Uses the C5 rollback; drafts and archived versions aren't offered |
| T8-F7 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| T8-S1 | must | Only allowed classes | Tamper with the request to include another teacher's class or another org's class | Refused by C5 (403/404); the picker never lists them |
| T8-S2 | must | Confirmation | Publish | An explicit confirm step naming the classes and student count; double-clicking publishes once |

## Performance

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| T8-P1 | must | Large diff | The C5-P1 2,000-idea versions | The screen renders in under 1 s; long sections collapse |

## Usability

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| T8-U1 | must | Plain language | Read the screen | No raw ids without names; the publish button says what will happen ("Publish to 1 class") |
| T8-U2 | must | Accessible | Keyboard and screen reader | The class picker uses labelled checkboxes; the result is announced |
