# QA criteria: A4 · Atlas agent with tools

Done when: Atlas answers with tools (searchIdeas, getDataChecks, getDiff, searchLibrary, draftRows).
Sources: `docs/ARCHITECTURE.md` §9 (Atlas: teachers; filled template, app guide, effective config; tools; can only draft, never writes curriculum data, matching D4), D11 (library use_for), D13; A1 gateway; A3; C2 checks; C5 diff; T2. Mock model in tests (tool-call script).

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| A4-F1 | must | Each tool works | Ask questions that need each tool ("which ideas mention clouds", "what blocks publishing", "what changed in the draft", "find the lab sheet on evaporation", "draft assessment rows for unit 2") | The matching tool is called with valid arguments and its result grounds the answer |
| A4-F2 | must | Tools, not stuffing (§9) | A 2,000-idea curriculum | The prompt stays under budget; facts come from tool calls, not a pasted curriculum |
| A4-F3 | must | Draft only (D4) | Ask Atlas to "fix the error" or "publish" | It drafts rows or explains the steps; no write to curriculum data, versions or pins happens |
| A4-F4 | must | Library settings (D11) | A document set to "tutor" or "off" for the class | searchLibrary as Atlas never returns it |
| A4-F5 | must | draftRows exports | Draft rows for a tab | Returned in the Curriculum Pack columns, downloadable as C6's drafts CSV |
| A4-F6 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |
