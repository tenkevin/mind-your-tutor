# QA criteria: C1 · CSV and XLSX import with column mapping

Done when: `fixtures/water-cycle` imports from the eight CSVs, `water-cycle.xlsx` and `pack.json` into identical parsed packs using the column mapping.
Sources: `docs/spec/` (tabs, columns, missing-value behaviour), `docs/ARCHITECTURE.md` §7 (connectors: import and export only, `ImportConnector`), D8, the F3 contracts in `@ideamap/contracts`, `fixtures/water-cycle/README.md`, and Teacher Settings → "Column mapping" in `project/Teacher Settings.dc.html`.

Boundary: C1 turns files into a parsed pack plus row-level problems. Whole-pack checks (unknown ids, loops) are C2; storing a version is C4.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C1-F1 | must | All three forms give the same pack | Import the eight CSVs, `water-cycle.xlsx` and `pack.json` | Three deep-equal parsed packs: 18 ideas, 31 links, 3 units, 3 categories, 18 assessment rows, 3 personas, 5 library rows, and the Course values |
| C1-F2 | must | Column mapping renames headers | Copy the CSVs, rename `requires` → `prereqs`, `standard_codes` → `ngss` and `idea_id` → `id`, then import with a mapping for those three | Same pack as C1-F1. With no mapping, the error names the missing required column and the tab |
| C1-F3 | must | Header matching is forgiving | Import with headers `Idea ID`, ` TITLE `, `Standard Codes` | They match `idea_id`, `title` and `standard_codes` (case, spaces and underscores ignored). Ambiguous matches are reported, never guessed |
| C1-F4 | must | Course is read as key/value | Import `Course.csv` and the Course sheet with keys in a different order and one blank row | Same Course object; unknown keys are reported as warnings |
| C1-F5 | must | Spreadsheet quirks are normalised | XLSX with `unit` stored as a number, `grade` as `6.0`, `due_date` as an Excel date serial and as text `2026-10-30`, `importance` as `"5"`; CSV with a UTF-8 BOM and CRLF line endings | Values match the contract types (integer unit, grade "6", ISO date); no BOM in the first header |
| C1-F12 | must | Percent and date cells from Excel (from F3 QA findings 2 and 3) | XLSX with `pass_mark` formatted as a percentage (stored as 0.7); `due_date` as a real date cell; run the import with `TZ=UTC`, `TZ=Pacific/Auckland` and `TZ=America/Los_Angeles` | `pass_mark` becomes 70, or the import warns, but never silently 0.7. `due_date` is the same calendar date in every time zone |
| C1-F6 | must | Missing-value behaviour follows the spec | Remove a required Ideas column; blank `relation` in one Links row; blank `importance` in another | A missing required column blocks the import with a clear error; the bad Links row is skipped with a warning naming its row; blank importance becomes 3 |
| C1-F7 | must | Missing optional tabs don't block | Import without Personas, Library and Categories | The import succeeds: built-in personas, an empty library and one category "Idea", as in the spec's missing behaviour, each with an info message |
| C1-F8 | must | CSV upload as a zip and as separate files | Import the eight CSVs zipped together, then as separate uploads | Same pack as C1-F1. Files are matched to tabs by name, ignoring case |
| C1-F9 | must | Extra columns are kept out of the pack | Add a column `teacher_scribbles` to Ideas | Not in the parsed pack; reported once as "ignored column" |
| C1-F10 | must | Connector interface matches §7 | Inspect `packages/connectors` | Each connector implements `ImportConnector` (`kind`, `parse(file)`); results go through the F3 contracts |
| C1-F11 | must | Package checks pass | `pnpm lint`, `format:check`, `typecheck`, `test`, `build` | All exit 0; CI green |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C1-S1 | must | Formulas are never evaluated | XLSX cells with `=HYPERLINK("http://x","y")`, `=1+1`, `+cmd`, `@SUM(A1)`; CSV cells starting with `=` | Read as plain text (the cached value or the literal string), never executed. Values beginning with `=`, `+`, `-` or `@` are flagged for C6 export escaping |
| C1-S2 | must | Oversized and malicious files are refused | Upload: a 60 MB CSV; a zip bomb (1 MB → 1 GB); an XLSX with 1,000,000 rows; a `.xlsm` with macros; a file named `.xlsx` that is really a PNG | Each is refused quickly with a clear message. Limits: 10 MB per file, 50,000 rows per tab, 100 MB unpacked. Macro files are rejected. Type is checked by content, not by extension |
| C1-S3 | must | XML parsing is safe | XLSX with an XXE payload in `sharedStrings.xml` and a "billion laughs" entity | No external fetch, no entity expansion, refused or parsed safely |
| C1-S4 | must | Zip paths can't escape | Zip containing `../../etc/passwd` and absolute paths | Nothing is written outside a temp area. Ideally nothing is written to disk at all |
| C1-S5 | should | Dependencies are clean | `pnpm audit` after adding the parsing libraries | No high or critical advisories; the libraries are actively maintained |

## Usability (teachers see these in the import screen)

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C1-U1 | must | Problems point to the cell | Trigger C1-F6 and an invalid `unit` | Each message names the file or sheet, tab, row number as the teacher sees it, column and value, in plain English (F3 style) |
| C1-U2 | must | A wrong file says what was expected | Upload a random spreadsheet with no matching tabs | One message that lists the eight expected tabs and points to the pack template |
| C1-U3 | must | All problems are returned together | A file with 5 problems across 3 tabs | All 5 reported at once, grouped by tab, with blocking problems first |
| C1-U4 | should | Mapping suggestions | Headers that are near misses (`requirement`, `standard`) | A suggested mapping the teacher can confirm, not an automatic one |
