# QA criteria: S2 · Student explorer

Done when: the student explorer draws the MapView for the class's pinned version and sends interaction events.
Builds on S10, which already draws the pinned version and opens read-only idea pages. S2 replaces S10's zero-progress state with M4's stored MapView and S1's live progress, and adds the events.
Sources: `docs/ARCHITECTURE.md` D2, D17, D19, §8.2, §8.4; M4; C5 (pinned version); S1; S5 components; `project/Idea Map Explorer v2.dc.html` (visual reference).

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| S2-F1 | must | Pinned version only (D2) | Class pinned to v1 while v2 is a draft | The explorer shows v1; never draft content |
| S2-F2 | must | Draws the stored MapView | Load the explorer | Uses M4's stored view (records `map.shown` with its id); locked ideas look locked and can't be opened |
| S2-F3 | must | Exact events (D19) | Open an idea, stay 47 s, leave; hover links, zoom, scroll | Sends `idea.opened` and `idea.active_time` = 60 (rounded); no hover, zoom or scroll events; batched with the offline queue |
| S2-F4 | must | Progress shown | After mastering an idea | Mastery and unlocks from S1 appear without a reload |
| S2-F5 | must | Matches the design | Compare with Idea Map Explorer v2 | Same map layout, idea cards and states, using Nocturne tokens |
| S2-F6 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |
