# QA criteria: C12 · Two-layer conceptual graph in the pack

Done when: per D41, a curriculum can mark its surface process ideas and its underlying causal-mechanism ideas, the checks keep prerequisites acyclic while allowing the surface loop, and the water-cycle fixture gains its mechanism layer.
Sources: `docs/ARCHITECTURE.md` D41 (procedural DAG; conceptual two-layer graph; trace-back goes to the mechanism layer, not around the loop; NGSS/CCSS standards), D8, D12; `docs/decisions/2026-10-29-prototype-spec.md` §5; `docs/spec/`; C1, C2, C3; `fixtures/water-cycle/`.

Boundary: pack data, checks, the fixture and one pure domain function. The Vault standards graph is C13; trace-back signals are M8; drawing the layers on the student map is M4/S2.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C12-F1 | must | Spec and contracts | Read `docs/spec/` and parse Ideas rows | Ideas gain `layer` ∈ process, mechanism (`both`: sheet seeds; missing means process, so single-layer packs such as kinematics are unchanged); mechanism ideas carry a `standard_code` (missing is a warning) |
| C12-F2 | must | Loop allowed only where it belongs | Import the water cycle with the process loop evaporation → condensation → precipitation → collection → evaporation expressed as Links, and every `requires` acyclic | No error. A `requires` cycle in either layer is still an error that blocks publishing (C2) |
| C12-F3 | must | Mechanism layer | Add mechanism ideas (thermal energy, phase change, gravity, droplet mass, topography) and make process ideas `require` them | Imports and checks pass; a mechanism idea that requires a process idea is a warning ("mechanisms underlie the process, not the other way round") |
| C12-F4 | must | Trace targets | Call the new pure function in `packages/domain` for a process idea | It returns that idea's unmastered prerequisites in the mechanism layer, deepest first, never a process-loop neighbour; for a single-layer pack it walks `requires` as before; property tests cover random acyclic graphs |
| C12-F5 | must | Fixture | Read `fixtures/water-cycle/` | CSV, XLSX and pack JSON carry the mechanism layer with NGSS codes; the README lists them; existing deliberate errors stay as documented |
| C12-F6 | must | Downstream intact | Run C3 derivation, C5 diff and C6 export on the new fixture | Derivation, layout and quizzes still succeed; the diff shows `layer` changes; exports roundtrip |
| C12-F7 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |
