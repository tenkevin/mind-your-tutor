# QA criteria: T2 · Curriculum data section: import, pipeline, data checks

Done when: import, pipeline steps and data checks render from the API, matching the design.
Sources: `docs/ARCHITECTURE.md` §7 (pipeline, errors block publishing), §11 (Curriculum data row; "Re-sync" becomes **Import new version**), D2, D12; `project/Teacher Settings.dc.html` (Curriculum data section); C4 import job and steps; C2/C2cx5 stored issues; `fixtures/water-cycle/` (1 error, 1 warning, 1 info); T1 shell; F5 policies; CXB items from `Codex-C4-review-7623133.md`, `Codex-C2cx5-review-7dd6511.md` and `Codex-C6-review-8cc23ab.md`.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| T2-F1 | must | Import new version | Choose `water-cycle.xlsx` in the section | A C4 import job starts; the button is labelled **Import new version** (not Re-sync) |
| T2-F2 | must | Pipeline steps render live | Watch the job | The six steps (Read sheet, Check data, Rank links, Lay out map, Make quizzes, Index library) show queued, running, done or failed from the API's `import_job.steps`, updating without a reload |
| T2-F3 | must | Data checks grouped by cause | When the draft is ready | Exactly 1 error (ground requires unknown aquifer), 1 warning (rain has no codes), 1 info (11 ideas lack media), grouped by cause, errors first, each with its fix tab and column |
| T2-F4 | must | Can't-publish state (D2) | With the sample's error | The draft is marked "can't publish yet" with the blocking issue; the section doesn't offer Publish (that's T8/C5) |
| T2-F5 | must | Draftable gaps don't block (D12) | Import a pack with an empty unit objective | Shown as a warning offering an Atlas draft; publishing isn't blocked by it |
| T2-F6 | must | Import failures | Upload a file missing a required tab column, and a non-spreadsheet | The job ends failed with C1's located problems shown; no draft is listed |
| T2-F7 | must | Source shown | After an import | Source file name, kind, checksum-based "unchanged since last import" note when re-importing the same file, and import time |
| T2-F8 | must | API wiring (CXB: Codex-C4-review-7623133.md) | Start the real API from `apps/api/src/index.ts` (not a test-only `buildServer`) | The import routes and authenticator are wired in the API bootstrap |
| T2-F9 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |
