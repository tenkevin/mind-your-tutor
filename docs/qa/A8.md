# QA criteria: A8 · Dual memory

Done when: per D28 and D29, short-term memory is the anonymised conversation; long-term summaries hold only misconceptions, what helped, preferred pace and up to five approved-category interests; the student can view, delete and turn off memory and the teacher can view and delete it; it lasts while enrolled, is covered by F6, and is never used for D20 inferences, D16 audits or D25 research.
Sources: `docs/ARCHITECTURE.md` D20, D22, D26–D29, §9, §10 (AI memory); A7; F6.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
