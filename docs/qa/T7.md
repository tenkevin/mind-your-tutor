# QA criteria: T7 · Persona editor: templates, variables, preview, test

Done when: templates edit with variable insertion, a filled preview and Test through the gateway.
Sources: `docs/ARCHITECTURE.md` D13, §6 (persona templates per field with "reset to curriculum"; fill on the server), §9 (variables `{name} {tone} {subject} {topic} {grade} {age} {peerAge} {style} {length}` live in `packages/ai`; templates are versioned records), §9 safety (fixed guardrails appended after templates; A2), §11 (AI personas & prompts); A1 gateway; `project/Teacher Settings.dc.html` (AI personas & prompts).

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|

| T7-F4 | must | Unknown variables | Type `{nickname}` | Flagged as unknown in the editor; saving is allowed or refused consistently with A1's behaviour, and the teacher is told which |
| T7-F5 | must | Test through the gateway | Press Test with a sample student message | The call goes through A1 (rate limits and redaction apply) and shows the reply; no model call from the browser |
| T7-F6 | must | Versioned (§9) | Save twice | Two template versions stored; the previous version can be viewed |
| T7-F7 | must | Guardrails stay | Delete all text from Milo's template and Test | The fixed guardrails are still appended by the server (§9); the editor says they're always added |
| T7-F8 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |
