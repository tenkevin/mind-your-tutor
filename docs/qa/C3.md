# QA criteria: C3 · Derivation: link ranking, layout, quiz generation

Done when: link ranking, ring layout and 8-question quiz generation run on import and are stored on the draft version; tests check the rules rather than exact output.
Sources: `buildGraph()` and `genQuiz()` in `project/Idea Map Explorer v2.dc.html`, `docs/ARCHITECTURE.md` §7 (derive step) and D6 (generation may vary but is stored), the design chat's map rules (`chats/chat1.md`: at most 3 links in and 3 out, most connected in the centre), `docs/spec/` (Categories, importance).

Boundary: C3 delivers `derive(pack, options)` in `packages/domain`, returning the derived data for a version. C4 calls it and stores the result. Choosing which questions a student gets per attempt is not C3's job.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C3-F1 | must | Link limits hold | Run `derive` on the sample and on 20 random packs | No idea has more than 3 kept outgoing or 3 kept incoming links. The limit is an option, default 3 |
| C3-F2 | must | Stronger links win | Packs where an idea has 5 outgoing links with importance 5, 4, 3, 2, 1 | The 3 highest are kept. Ties are broken the same way on every run (for example by row order) |
| C3-F3 | must | Matches the prototype on the sample | Run `derive` on `fixtures/water-cycle` | 27 links kept, 4 hidden, with the hidden ones listed. Centre idea: Evaporation (`evap`). Inner ring: exactly `cond`, `prec`, `temp`, `ocean`, `cycle` and `vap`, in any order (verified against the prototype's `buildGraph`) |
| C3-F4 | must | Layout rules | Inspect positions on the sample and random packs | One centre idea (most kept links; ties go to the higher importance sum); the next 6 in ring 1; everyone else in ring 2; every idea gets a position; no two ideas share a position |
| C3-F5 | must | Quiz bank per idea | For every idea in the sample | At least 8 questions per idea. Each question has a prompt, text, options, exactly one correct answer among the options, an explanation, and the link it tests (or none for category questions) |
| C3-F6 | must | Question content is right | Check every question on the sample | "Which idea completes the link?" answers are the true neighbour and distractors are not neighbours; true statements match a kept link; false statements are not any link in the pack (kept or hidden); no duplicate questions for an idea |
| C3-F7 | must | Categories come from the pack | Rename categories in a copy of the sample to `Cause`, `Effect`, `Object`, `Place` | The "What kind of idea is it?" question uses those four names. The prototype's hard-coded `Process / Force / Thing` must not appear. With one category, the question is skipped |
| C3-F8 | must | Sparse ideas still get a full quiz | An idea with exactly one kept link; an idea with none | One link: still 8 questions, as in the prototype's padding. None: fewer questions, with a flag that C2 or the UI can show. No crash, and no question that is false by accident |
| C3-F9 | must | Output is typed and stored-ready | Inspect the return type | Typed via `@ideamap/contracts` (the version's derived data), JSON-serialisable, and round-trips through `JSON.parse(JSON.stringify())` unchanged |
| C3-F10 | must | Rule-based tests | Read the tests | Tests assert the rules (C3-F1, F2, F4 to F8), not exact snapshots of random output. One test checks C3-F3 |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C3-S1 | must | Text stays plain | A relation `</script><b>x` and a title with HTML | Copied as plain text into questions; nothing interpreted |
| C3-S2 | must | No prototype pollution through ids | Use objects keyed by ids, or `Map`; test with ids `constructor`, `toString`, `hasOwnProperty` (valid slugs) | Correct results; `Object.prototype` unchanged |
| C3-S3 | must | Pure function | Inspect imports | No network, file, database or model calls. Any randomness takes an explicit seed option |

## Performance

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C3-P1 | must | Sample is fast | Time 50 runs | Median under 20 ms |
| C3-P2 | must | Large packs scale | 2,000 ideas, 6,000 links | Under 1 second for ranking, layout and every quiz bank |

## Usability (students answer these questions)

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C3-U1 | must | Questions read naturally | Read all questions for 3 ideas on the sample | Sentences built from relation phrases read as English ("The Sun powers Evaporation."), with no doubled spaces, no stray "…" and nothing like "undefined" |
| C3-U2 | must | Explanations teach | Read the explanations for wrong answers | Each states the true link from the map ("The map says: …") |
| C3-U3 | should | Layout keeps neighbours close | Look at the inner ring order on the sample | Adjacent ring-1 ideas are linked where possible, as in the prototype's ordering |
