# QA criteria: F2 · Port Nocturne tokens and components to packages/ui

Done when: `packages/ui` exports Nocturne tokens and the btn, input, tag, table and field classes.
Sources: `project/_ds/nocturne-*/styles.css` and `readme.md` (the design system), `project/Teacher Settings.dc.html` (how the classes are used), `docs/ARCHITECTURE.md` §9 (accessibility, WCAG 2.1 AA).

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| F2-F1 | must | Every design token is ported with identical values | Parse all custom properties in `:root` of the prototype's `styles.css` and of the package's CSS output, then diff | Same names and same values; nothing missing; any extras documented |
| F2-F2 | must | The required classes exist with all their variants | Check the built CSS for `.btn`, `.btn-primary`, `.btn-secondary`, `.btn-ghost`, `.btn-icon`, `.btn-block`, `.input`, `textarea.input`, `.field > label`, `.tag`, `.tag-accent`, `.tag-accent-2`, `.tag-neutral`, `.tag-outline`, `.table` with `th`, `td` and row rules | All present, with the same declarations as the prototype (hover, active, disabled and focus-visible states included) |
| F2-F3 | must | Apps can use it with one import | In `apps/teacher`, import the package's stylesheet and render a button of each variant, an input, a select, a textarea, a field label, each tag variant and a 3-row table | Renders with no build warnings; the computed styles match F2-F2 |
| F2-F4 | must | Visual match with the prototype | Build a reference page with the F2-F3 elements. Screenshot it, and the same elements in `project/Teacher Settings.dc.html`, at 1280 px wide with Chromium | No visible difference in colour, radius, padding, font or weight. Attach both screenshots to the report |
| F2-F5 | should | Token names are available to TypeScript | Import the token list or type from `@ideamap/ui` in a `.ts` file | Typed exports exist (for example a `tokens` object or a `Token` union) |
| F2-F6 | must | Package checks pass | `pnpm --filter @ideamap/ui build test typecheck` and `pnpm lint` | All exit 0 |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| F2-S1 | must | No third-party network requests from styles | Load the F2-F3 page with network logging | No requests to any external host. The prototype's Google Fonts `@import` is replaced by self-hosted Inter, because student IP addresses must not go to third parties (K-12) |
| F2-S2 | must | Font licence is compatible | Check the bundled font's licence file | Inter under the SIL Open Font License, with the licence included in the package |
| F2-S3 | should | No CSS that loads remote resources | Search the CSS for `url(http`, `@import url(http` and `image-set(http` | None |

## Performance

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| F2-P1 | must | Stylesheet is small | Measure the gzip size of the built CSS (fonts excluded) | Under 10 KB |
| F2-P2 | must | Fonts don't block text | Inspect the `@font-face` rules and font files | woff2 only, Latin subset, `font-display: swap`, total under 150 KB for the weights used (400, 500, 600, 700) |
| F2-P3 | should | No JavaScript runtime cost | Check the package's JS output | Zero or near-zero runtime JS (token constants only) |

## Usability

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| F2-U1 | must | Text contrast meets WCAG AA | Compute the contrast of `--color-text` and `--color-neutral-300/400/500` on `--color-bg` and `--color-surface`, and of `.btn-primary` and `.tag-*` text on their backgrounds | Body text at least 4.5:1, large text and UI parts at least 3:1. List any token pair below the bar with the page that uses it |
| F2-U2 | must | Keyboard focus is visible on every interactive class | Tab through the F2-F3 page | Every button, input, select and textarea shows a visible focus ring |
| F2-U3 | must | Disabled state is obvious | Render disabled `.btn` and `.input` | Lower opacity and a `not-allowed` cursor, matching the prototype |
| F2-U4 | should | Works at phone width | View the F2-F3 page at 400 px | No horizontal scroll; inputs fill their container |
| F2-U5 | should | Developers can find out how to use it | Read the package README | Lists every class and token group with one example each |
