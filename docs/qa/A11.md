# QA criteria: A11 · Grounded tutoring: sparring-partner mode when no verified source covers the question

Done when: per D35, Ms. Ivy answers factual questions only from verified assets, citing the passage; when none covers the question she states that and guides the student's reasoning with questions instead of stating facts. Covered by A5 eval cases.
Sources: `docs/ARCHITECTURE.md` D35, D31 (vault and class uploads), D11 (`use_for`), §9 (Ms. Ivy gets library passages), §12 q15 (what counts as verified; built to the stated assumption, behind one function so it can change); A1 gateway, A2 guardrails, A3 `searchLibrary`, A5 eval harness. Tests use the A1 mock model and A3's deterministic embedder; synthetic prompts only.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| A11-F1 | must | Grounded answer | Ask about something a vault passage covers | The reply rests on retrieved passages and cites document and page or section; the prompt sent to the model carries those passages and an instruction to use only them |
| A11-F2 | must | Sparring mode | Ask about something no verified asset covers (search returns nothing above the relevance threshold) | The gateway marks the turn `ungrounded`; the reply says plainly the class materials don't cover it, states no new facts, and asks at least one question that scaffolds the student's reasoning or points to a covered idea |
| A11-F3 | must | Verified scope (D35, §12 q15) | Repeat F1 with a document set to `off`, an archived document, another class's upload, and this class's upload with `use_for` agent | None of these grounds a student answer; this class's upload with tutor or both does. The scope is decided in one function |
| A11-F4 | must | No internet | Inspect the gateway's student path | No web search, browsing or URL fetch tool is offered to the model, and no request leaves for any host but the model provider |
| A11-F5 | must | Recorded, not recomputed | Run F1 and F2 | The mode (`grounded` or `ungrounded`) and cited passage ids are stored with the AI output and its `ai.output_shown` event (rule 2 of §8); nothing about the student beyond A1's fields is added |
| A11-F6 | must | Evals | Run the A5 harness | Each grade band has at least one grounded and one ungrounded case; a reply that states an uncovered fact fails the case |
| A11-F7 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |
