# QA criteria: C16 · Lay out each idea scope separately

Done when: per D43, derivation runs the existing ranking and layout code on each scope's ideas, so the main map is laid out from core ideas only. Prerequisite and extension ideas get their own layouts, and links between scopes are kept for the zoom views. A pack without `scope` derives exactly as before.
Sources: `docs/ARCHITECTURE.md` D43, D12, §5; `docs/decisions/2026-10-29-water-cycle-pilot-graph.md` (Layout check); `packages/domain/src/derive/` (rank, layout, quizzes); C3, C14.

Boundary: `packages/domain` derivation and the derived contract. The algorithm stays as it is (centre = most links, inner ring of 6, outer ring near its neighbours). Drawing the views is M4/S2/S9.
