# QA criteria: C15 · Vault provenance: source, licence and attribution

Done when: per D31 (as amended 2026-10-29), every vault item and Library row keeps `source`, `license_type` and `attribution_string`. Attribution is shown wherever the licence requires credit, including the tutor's citations. A non-commercial (NC) or share-alike (SA) item enters the vault only after an admin approves it.
Sources: `docs/ARCHITECTURE.md` D31 (amended), D35 (citations), D40 (allow-list pattern), D11, D3; `docs/spec/`; A3 (vault and RAG), C10 (licence allow-list configuration), C1, C2, C5, C6.

Boundary: Library tab columns, vault document records, the approval gate, and attribution in retrieval citations. Class uploads (the unofficial tier) are out of scope and need no licence fields.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| C15-F1 | must | Spec and contracts | Read `docs/spec/` and parse Library rows | Library gains `source`, `license_type` and `attribution_string` (`both`), each with its missing behaviour and an example (OpenSciEd Unit 6.3, CC-BY-4.0, its attribution line) |
| C15-F2 | must | Missing provenance blocks | Import a Library row with no source or licence, and a CC-BY row with no attribution | Each is a data-check **error** that blocks publishing, located by tab, row and column |
| C15-F3 | must | Licence list is configuration | Import rows under an allow-listed licence, an unknown licence, and a CC-BY-NC or CC-BY-SA licence | Allow-listed licences pass. An unknown licence is an error. NC and SA items import but stay **pending admin approval** and are not retrievable until an admin approves them. The licence list, including which licences need approval, is configuration (shared with C10's), not code |
| C15-F4 | must | Admin approval | Approve, as an admin, a pending NC item; try the same as a teacher and an author | The admin's approval is audited (actor, item, licence) and makes the item retrievable. A teacher or author gets 403 |
| C15-F5 | must | Kept with the vault | Replace a vault document with a new version, then take it out of use | Provenance is versioned with the document and kept after it is taken out of use (D31: never deleted) |
| C15-F6 | must | Attribution in citations | Ask the tutor a question answered from a CC-BY vault item | The grounded answer's citation shows the item's attribution string. An item whose licence needs no credit shows its title only |
| C15-F7 | must | Diff and export | Change an item's licence, then export | C5 diff shows the provenance change; C6 export round-trips all three columns |
| C15-F8 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build and plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |
