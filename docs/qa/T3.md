# QA criteria: T3 · Course details with layered config

Done when: Course details edit class overrides and show whether each value comes from the curriculum or the class.
Sources: `docs/ARCHITECTURE.md` §6 (layered configuration), §11 (Course details row), D3 (one curriculum shared by many classes), §10 (Access, AuditEvent); `project/Teacher Settings.dc.html` (Course details section); `docs/spec/curriculum-pack.fields.json` (Course tab); T1 shell; F5 roles; CXB item from `Codex-F3-contracts.md` F3-S2.

Fixture: one curriculum (water-cycle, published) shared by classes A and B; teacher TA owns A, TB owns B; an author.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| T3-F1 | must | Fields from §6 | Open Course details for class A | Subject, topic, whole-map objective, grade level and standards framework are shown with the effective value |
| T3-F2 | must | Origin per field (§6) | With no overrides, then after overriding topic in A | Each field shows "from curriculum" or "this class"; after the edit only topic says "this class" |
| T3-F3 | must | Override is class-only (D3) | Override topic in A; open B as TB | B still shows the curriculum value; the curriculum default is unchanged |
| T3-F4 | must | Reset to curriculum | Reset topic in A | A shows the curriculum value again, marked "from curriculum"; the override row is removed, not set to an empty string |
| T3-F5 | must | Autosave via T1 | Edit a field | The header shows Saving then Saved; a reload shows the saved value |
| T3-F6 | must | Authors edit defaults | As an author, edit the curriculum default subject | Every class without an override shows the new value; classes with an override keep theirs. Teachers can't edit defaults |
| T3-F7 | must | Grade drives reading level (§6) | Change A's grade | The effective config the gateway would use (A1 `fill`, or the effective-config API) reflects the new grade |
| T3-F8 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| T3-S1 | must | Only the class's teacher (or an admin) edits it | As TB, PUT an override for class A; as a student; signed out; other org | 403 / 403 / 401 / 403; nothing saved. Routes declare F5 policies and are in the every-route sweep |
| T3-S2 | must | Validated input | Send an unknown field, an over-long topic, a grade outside K-12 and HTML in the objective | 400 with a located message; stored text is rendered as text, never HTML |
| T3-S3 | must | Audit (§10) | Override, reset and edit a default | Each writes an `AuditEvent` with actor, class or curriculum, field, before and after |
