# QA criteria: A3 · Resource library and RAG indexing, with per-class settings and uploads

Done when: library uploads are chunked and embedded, and searchLibrary returns ranked passages. Per D11, a class can set each shared document to agent, tutor, both or off, and upload its own documents. A class's search covers the shared library plus its uploads, with its settings applied, and never returns another class's uploads. ClassConfig contracts gain the library settings. Vector search always filters by curriculum (and by class for uploads) or uses hnsw.iterative_scan, so row-level security never returns fewer than k results.
Sources: `docs/ARCHITECTURE.md` D11, §5 (library_doc, chunk, ClassLibrarySetting, class uploads), §7 (library indexing is its own job), §9 (Ms. Ivy gets library passages; Atlas's searchLibrary), §12 question 6 (embedding model open); F4/F4b tables; A1 gateway; F6 inventory. Embeddings use a **mock embedding provider** in tests.

| A3-F6 | must | Contracts | Parse ClassConfig with library settings | The `use_for` enum is validated; unknown documents are rejected |
