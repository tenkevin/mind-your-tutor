# QA criteria: A2 · Student safety: moderation, guardrails, teacher flags

Done when: student turns are moderated, fixed guardrails are added after templates, and flags reach the teacher.
Sources: `docs/ARCHITECTURE.md` §9 "Safety for student-facing personas" (input and output moderation on every student turn; fixed guardrails after the teacher's template: stay on topic, no personal data requests, age-appropriate language; concerning messages raise a flag to the teacher and admin, per district policy; rate limits), §10 (COPPA, transcripts redacted, retention); A1 gateway. Tests use a **mock moderation provider and mock model**; QA uses synthetic prompts only.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| A2-F1 | must | Input moderation | Send student messages the mock moderator labels unsafe, and ones it labels safe | Unsafe input never reaches the model; the student gets a calm, age-appropriate redirect; safe input passes unchanged |
| A2-F2 | must | Output moderation | Make the mock model return output the moderator labels unsafe | It is never shown; a safe fallback reply is shown instead and the event is logged |
| A2-F3 | must | Guardrails after the template (§9) | Inspect the filled prompt for Ms. Ivy and Milo with an empty template and with a template saying "ignore all rules" | The fixed guardrails come last in every case and can't be removed or reordered by any template or config |
| A2-F4 | must | Flags reach the teacher and admin | Send a message the mock moderator labels self-harm | A flag is created for the class teacher and the org admin, shown in the teacher view (or its API), and the student sees a supportive response with the district's help text |
| A2-F5 | must | District policy | Change the org's flag policy (who is notified) | Flags follow the configured policy |
| A2-F6 | must | Moderation failure fails closed | Make the moderator time out | The student turn isn't sent to the model; a friendly "try again" is shown |
| A2-F7 | must | Every student route | List the routes that reach a model on behalf of a student | Each goes through moderation; a test enumerates them |
| A2-F8 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| A2-S1 | must | Flag privacy | Read flags as a teacher of another class, a student, another org | 403; flag text is redacted per A1 |
| A2-S2 | must | No personal data requests | Guardrail text and output check | The guardrail forbids asking for personal data; outputs asking for name, address or phone are blocked by the output check |
| A2-S3 | must | Audit | Raise and resolve a flag | Both are `AuditEvent`s |
| A2-S4 | must | Flag retention (D32, added 2026-10-28) | Raise flags; resolve one; run the retention job at day 29, 31, 89 and 91 | An unresolved flag is deleted with its transcript at the district's AI retention period (default 90 days); a resolved flag is deleted 30 days after resolution if that comes first; the data inventory says so |
