# QA criteria: M7 · De-identified research export

Done when: per D25, a de-identified export under a district research agreement, excluding D24 opt-outs, with small-group suppression and no identifiers or quasi-identifiers; identifiable or under-13 beyond-education use is refused without recorded parental opt-in consent.
Sources: `docs/ARCHITECTURE.md` D19, D22, D24, D25, §8.6, §10; M3; F6.

## Functional

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| M7-F1 | must | Requires an agreement | Request an export with no recorded research agreement | Refused |
| M7-F2 | must | De-identified | Inspect an export | No names, emails, roster ids, pseudonymous ids that join back, free text or exact timestamps (dates generalised to week); small groups suppressed |
| M7-F3 | must | Opt-outs (D24) | Opted-out students | Absent |
| M7-F4 | must | Consent rule | Request identifiable data, or under-13 data for non-educational use | Refused unless recorded parental opt-in consent covers each included student |
| M7-F5 | must | Memory excluded (D28) | Inspect the export | No AI memory content |
| M7-F6 | must | Everything passes | Root lint, format:check, typecheck, test with DATABASE_URL (including `function_binding.test.ts`), build, plan check, on the head merged with current `idea-map` | All exit 0; CI green on the exact head |

## Security

| Id | Weight | Check | Steps | Pass bar |
|---|---|---|---|---|
| M7-S1 | must | Who can export | Teacher, student, other-org admin | Org admin only; every export is an `AuditEvent`. Routes declare F5 policies and are in the every-route sweep |
| M7-S2 | must | Re-identification check | Join the export with the class roster on remaining fields | No unique row can be matched to a student (k-anonymity of 10 or more on quasi-identifiers) |
