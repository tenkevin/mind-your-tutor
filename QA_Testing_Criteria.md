# Stage 1
- [ ] Pipeline flow: Generated schema x Monitoring --> AI --> Adaptive Learning paths + Personalized Assessments
- [ ] Monitoring data should have the ability to intake user inputs, and add catagories like wrong answers, time hovered over the wrong answer, seconds paused before answering, etc. (It should be flexible in addting catagorical variables as well as property)
- [ ] Generated schema should be able to: 
	- [ ] take in whole curriculums
	- [ ] break down into lesson objectives
	- [ ] break further into knowledge components
	- [ ] AI/Manually should have enough instructions/prompt to plot the schema with correct reference to the knowledge components for a MVP personalized learning path
		- [ ] The KC graph should also be able to be changed by a SME
	- [ ] The final product should be displaying the schema for the user to see
- [ ] The monitoring should focus on analyzing choice, persistence, and mental effort.
- [ ] The result of assessment and quizzes should poll for cirriculum effectiveness and efficiency.
